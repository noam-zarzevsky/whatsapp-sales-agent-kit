# המוח - מלקוח עסקי לסוכן מכירות

> סקיל ב-Claude Code. גרסה 0.1. נבנה אוטומטית מהגרסה שבפיתוח - בהוראות "המפעיל" הוא מי שמריץ את המוח.

## מה הוא עושה

המוח הוא **אדריכל, לא בנאי**: מקבל משימה, מפרק אותה ללבנים, ובוחר לכל לבנה כלי - סקיל, סוכן, pipeline
או פלאגין. המסלול המוכן הראשון - **סוכן מכירות ללקוח עסקי**, בשלבים. בכל שלב המפעיל מאשר לפני שממשיכים.

| שלב | מה קורה | התוצר בתיק | מצב |
|---|---|---|---|
| 0 | פתיחת תיק - מה הלקוח, מה המוצר, והאם הוא מתאים לסוכן | `STATUS.md` | ✅ |
| 1 | היכרות עם העסק - ראיון, מקורות קיימים | `profile.md` | ✅ |
| 2 | מחקר שוק - מתחרים, מחירים, קהל | `market.md` · `research/` | ✅ |
| 3 | אסטרטגיה, ובדיקת המסר מול לקוחות מדומים (🐭 פינקי) | `strategy.md` · `pinky/` | ✅ |
| 4 | קובץ המוצר - מה שהמנוע מריץ | `engine/knowledge/<slug>.md` | ✅ |
| 5 | 🐭 פינקי מול הסוכן עצמו | - | ✅ |
| 6 | מסירה - בדיקה לפני עלייה לאוויר, ומסמך ללקוח | - | ✅ |

**החוק שהכל נשען עליו:** עובדה נכנסת לקובץ המוצר רק ממסמך שהלקוח מסר או מהכרעה מפורשת שלו - לא ממה שנשמע
סביר. כל שורה מסומנת ✅ מאושר · ⚠️ לא סגור · ❌ חסר, עם המקור שלה.

## מה יש כאן

| תיקייה | מה |
|---|---|
| `plugin/` | הפלאגין: `skills/brain/` (המוח, וההוראות לכל שלב ב-`references/`) ו-`skills/pinky/` (לקוחות מדומים) |
| `plugin/skills/brain/references/product-brief/` | התבנית של קובץ המוצר, ומה סוכן כזה דורש מהעסק |
| `helpers/` | רשימות על העוזרים - למשל כלי מחקר בתשלום ומה הם עולים |
| `clients/` | כאן המוח פותח תיק לכל לקוח. בערכה אין תיק לדוגמה. קובץ מוצר לדוגמה (פרויקט בדוי) - `engine/knowledge/demo-project-sales.md` |

## איך מפעילים

1. פותחים את תיקיית `course-edition/` (עם `brain/` ו-`engine/`) כתיקיית העבודה ב-Claude Code
2. מתקינים את הפלאגין - קובץ ה-`.plugin` מגיע עם הערכה הארוזה
3. כותבים: **"המוח, לקוח חדש"** - או "נמשיך עם <לקוח>" לתיק קיים

**תיקים חדשים** נפתחים ב-`brain/clients/<slug>/`. **קובץ המוצר** נכתב ל-`engine/knowledge/`, ומשם המנוע קורא אותו.

**עוזרים שהמוח נעזר בהם:** נתן (סוכן הקורס) לפרופיל העסקי ולאפיון הקהל, וכלי מחקר בשלב 2 - חלקם בתשלום,
ורק באישור המפעיל.
