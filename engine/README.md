# המנוע - סוכן מכירות בוואטסאפ

> הקוד כאן הוא עותק של מה שרץ בענן - נבנה אוטומטית. כל מה שאישי למוכר מגיע ממשתני סביבה.

## הקבצים

| קובץ | מה הוא עושה |
|---|---|
| `src/run.py` | הלולאה: קורא הודעות, מנתב, שולח למודל, שולח ללקוח, קובע פגישות, מעקב |
| `src/router.py` | של מי הליד: לפי משפט הטריגר, ובלי לגעת בלידים של סוכן אחר על אותו מספר. בלי המשפט - לפי המילים שכתב (`INTENT_WORDS`), ובלי שום רמז - פתיחה קבועה (`BUSINESS_NAME`), והתשובה מנותבת באותה דרך |
| `src/engine.py` | ההוראות למודל, והבדיקות בקוד שכל תשובה עוברת לפני שהיא יוצאת |
| `src/calendar_meetings.py` | מועדים פנויים מהיומן, וקביעה עם בדיקה חוזרת רגע לפני |
| `src/notify.py` | העברות לבעלים בוואטסאפ, וסיכום הבוקר |
| `src/cards.py` | כרטיס לכל ליד - היסטוריה, מה ידוע עליו, העברות, פגישה |
| `src/whapi.py` | החיבור לוואטסאפ |
| `src/dry_run.py` | הרצה יבשה מול מקרים מקובץ המוצר - בלי וואטסאפ |
| `knowledge/` | קבצי המוצר, המלאי והתמונות. הדוגמה - פרויקט בדוי: `demo-project-sales.md` |
| `tests/` | בדיקות בלי רשת: המודל והוואטסאפ מוחלפים בזיוף |

## קובץ המוצר - מה הקוד קורא ממנו

רוב הקובץ הוא טקסט שהמודל קורא. **כמה חלקים הקוד עצמו קורא, ולכן הפורמט שלהם מחייב:**

- **בראש הקובץ (frontmatter):** `keyword` - החלק הקבוע של משפט הטריגר ("לפרטים על רכישת"). `inventory` - קובץ
  מלאי מאותה תיקייה, אם יש
- **סעיף 3 - העלויות:** השורה שמתחילה ב-`>` - הניסוח שחייב להופיע בכל הודעה עם מחיר
- **סעיף 5 - הפגישה:** שורות `ימים ושעות` (`א'-ה' 10:00-16:30 · ו' 09:00-12:30`) · `כמה זמן` (`60 דקות`) ·
  `איפה` · `מתי לא` - אם יש בה "אחרי HH:MM", שעה מאוחרת יותר נדחית בנימוס, בלי העברה לבעלים. בלי שעות או
  משך - הסוכן לא קובע פגישות
- **סעיף 7 - חומרים:** טבלה עם עמודות `מזהה`, `חומר` (הכיתוב שנשלח עם התמונה) ו-`קובץ` (נתיב בתוך
  `knowledge/`)
- **סימן בדיקה 🧪:** השירות מסרב לעלות למצב `live` עם קובץ ששמו מסתיים ב-`.test`, או כשיש בו 🧪 - גם בהסבר

## הרצה במחשב

```
pip install -r requirements.txt
python tests/routing_check.py        # וכל שאר הבדיקות - בלי מפתחות
python src/dry_run.py demo-project-sales
python src/run.py --dry              # קורא מהוואטסאפ, לא שולח ולא שומר
```

## עלייה לענן (Railway)

1. שירות חדש, והמשתנים מ-`.env.example` בלשונית Variables
2. דיסק קבוע (Volume), ו-`DATA_DIR` שמצביע אליו - אחרת הכרטיסים נמחקים בכל עלייה
3. `railway up` מהתיקייה - `Procfile` מריץ `python src/run.py --loop`
4. ביומן הפעולות צריכה להופיע שורת הפתיחה: `▶ מצב: test | ... | מוצרים - ...`
5. בדיקה מהנייד: הודעה עם משפט הטריגר, והמשך שיחה. `AI אפס` מהנייד של הבעלים מאפס את השיחה
6. `MODE=live` - רק אחרי שיחה שלמה שעברה

## פקודות מהנייד של הבעלים

- `AI אפס` - מאפס את השיחה שלך (לבדיקה מחדש). `AI אפס 050-1234567` - של מספר אחר. גם `אפס AI` עובד
- הודעה אחרת שמתחילה ב-`AI` - לא נענית כליד
